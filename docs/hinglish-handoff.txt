Reproduce
1. Install JDK 17+, Android SDK and NDK as described in README.md, plus ffmpeg for fixtures.
2. Run gradlew.bat :app:testDebugUnitTest.
3. Run gradlew.bat :app:assembleDebug :app:assembleDebugAndroidTest.
   To rebuild the native decoder explicitly, add :app:externalNativeBuildDebug.
4. Resolve the actual APK location from the generated APK listing metadata.
   With android.injected.build.abi, Gradle can write app/build/intermediates/apk/...
   instead of app/build/outputs/apk/...; stale APKs may remain in the other folder.
   Check versionName/versionCode and timestamps before installing.
5. Use adb -s SERIAL install -r -t PATH for both the arm64 debug app and androidTest APK.
   Preserve app data; no uninstall or pm clear is necessary.
6. Create English video: powershell -ExecutionPolicy Bypass -File tools/make-caption-fixture.ps1.
7. For synthetic Hindi fixtures, optionally install Python edge-tts and generate audio:
   python -m edge_tts --voice hi-IN-MadhurNeural --file tools/fixtures/hinglish-male.txt --write-media build/hinglish-input.mp3
   python -m edge_tts --voice hi-IN-SwaraNeural --file tools/fixtures/hinglish-female.txt --write-media build/hinglish-second-input.mp3
   This TTS tool uses Microsoft's online service; fixtures contain only supplied synthetic text.
8. Make each audio file into a 12-second video, substituting INPUT and OUTPUT paths:
   ffmpeg -y -f lavfi -i color=c=0x15304a:s=640x360:r=30:d=12 -i INPUT.mp3 -t 12 -c:v libx264 -pix_fmt yuv420p -c:a aac OUTPUT.mp4
9. Push each video into /sdcard/Android/data/com.anintellectualcompany.masterclip/files/.
10. Run the production speech path through instrumentation:
   adb -s SERIAL shell am instrument -w -e input /sdcard/Android/data/com.anintellectualcompany.masterclip/files/hinglish-second-input.mp4 -e expected bhai,aaj,bahut,accha,tum,ho,hum,khelenge com.anintellectualcompany.masterclip.test/com.anintellectualcompany.masterclip.engine.CaptionSmokeRunner
   For the male fixture, use expected namaste,aaj,hum,editing,bahut,accha,sahi.
   For the English fixture, omit expected (defaults to captions).
   These checks intentionally test Hindi retention and export, not perfect transcript matching.
11. A pass returns INSTRUMENTATION_CODE: -1 plus PASS and an output filename.
    adb itself can exit 0 for a failed test; inspect the instrumentation result.
    Pull caption-smoke-output.mp4 after each run because the next run overwrites it.
12. Runner options language, model and prompt are diagnostic overrides. Omit them to test
    the actual production Speech.transcribe path. They bypass that path when language is set.

Source map
- Speech.kt: download, PCM decoding, recognition, timed-word normalization.
- whisper_jni.cpp: native decoder parameters and word timestamp export.
- Hinglish.kt: Hindi-to-Roman conversion rules and common spelling dictionary.
- Captions.kt / ClipEngine.kt: subtitle selection, clip slicing and speech fallback.
- SpeechTest.kt / EngineTest.kt: caption regression tests.
- CaptionSmokeRunner.kt: on-device decoder, recognizer and renderer check.
